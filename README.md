# Studio 2 Aviation

The SCB Studio 2 Thursday happy hour board game.

**Play:** https://karshisdesigns.github.io/studio2-aviation/

- Open the link on the big screen. Everyone else scans the QR code in the name bar to play from their phone. No app or sign-in needed.
- The Back Room (code 67) is where players, prizes, squares and the budget are edited.
- The shared save, live phone play and prize photos run on a free Supabase project (`studio2-aviation`).
- A small daily GitHub Action keeps the free Supabase project from pausing.
